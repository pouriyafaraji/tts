# PersianEmoTTS

تبدیل **متن فارسی** به **گفتار احساسی**. کاربر جمله را می‌نویسد؛ خروجی صدای فارسی با کیفیت (Piper Mana / Ganji) است که خشم، شادی، اندوه، ترس، شگفتی یا حالت خنثی را در خود صدا حمل می‌کند — نه فقط در معنی کلمات.

نوت‌بوک اصلی را در کولب اجرا کنید:

**[`PersianEmoTTS.ipynb`](PersianEmoTTS.ipynb)** → Runtime → Run all  
GPU T4 توصیه‌شده است (CPU هم برای Piper کافی است).

---

## این پروژه چه می‌کند؟

1. متن فارسی را نرمال می‌کند (ارقام، حروف عربی/فارسی، تشخیص احساس از روی خود جمله).
2. گفتار را با **Piper منجمد** می‌سازد — همان ستون‌فقرات باکیفیت نوت‌بوک‌های استاد (Mana زنانه، Ganji مردانه).
3. یک **Emotion Controller** با مقیاس λ (ایدهٔ TTS-CtrlNet) بردار استایل را روی سیگنال اعمال می‌کند: سرعت، F0، دامنهٔ زیروبمی، فرمنت، انرژی، درخشندگی، jitter، مکث، کانتور (Praat PSOLA).
4. همان جمله را با چند احساس می‌سازد تا احساس از **صدا** بیاید نه از واژه‌ها.
5. ارزیابی می‌کند: جداسازی آکوستیک، SVM-SER روی ShEMO (پروتکل AutESD)، RTF، CER با Whisper.

## معماری

```
متن فارسی
  → Frontend (normalize + emotion planner)
  → Frozen Piper (Mana / Ganji)
  → Emotion ControlNet-style style vector  (λ)
  → Praat PSOLA + energy / tilt / pause
  → WAV
```

ستون فقرات TTS **یخ‌زده** می‌ماند (کیفیت فارسی خراب نمی‌شود). احساس یک شاخهٔ کنترل است.

## مقالات ریپو که در طراحی استفاده شده‌اند

| مقاله | استفاده |
|---|---|
| TTS-CtrlNet (Jeong et al. 2025) | فریز کردن TTS ازپیش‌آموزش‌دیده + Control Scale λ |
| StyleTTS 2 (Li et al. 2023) | احساس به‌صورت بردار استایل (F0 / انرژی / دیرش) |
| EmoVoice (Yang et al. 2025) | برچسب احساس + ارزیابی SER |
| AutESD (Rahmati et al. 2026) | چهار احساس فارسی خنثی/شادی/خشم/اندوه و UAR |
| ShEMO (Mohamad Nezami et al. 2019) | دیتاست عمومی احساسی فارسی برای SVM-SER |
| PersianVox (2026) | اهمیت پروزودی در TTS فارسی |
| نوت‌بوک‌های استاد | Piper Mana/Ganji، G2P، بنچ‌مارک RTF، Gradio |

AutESD هنوز عمومی نیست؛ ShEMO همان منبعی است که خود AutESD به‌عنوان کار قبلی فارسی به آن ارجاع می‌دهد.

## نحوهٔ اجرا در Colab

1. فایل `PersianEmoTTS.ipynb` را در Google Colab باز کنید (یا این ریپو را Clone کنید).
2. Runtime → GPU (T4) اگر در دسترس است.
3. **Run all**.
4. سلول **Same-text emotion demo** شش نسخه از یک جملهٔ خنثی را پخش می‌کند. با گوش دادن باید خشم، شادی و اندوه را از هم تشخیص بدهید.
5. سلول **Acoustic gates** باید `PASSED` چاپ کند؛ در غیر این صورت نوت‌بوک متوقف می‌شود.
6. سلول Gradio یک لینک `share` می‌دهد.

اگر نوت‌بوک را بدون کل ریپو آپلود کنید هم کار می‌کند: موتور داخل خود نوت‌بوک embed شده است.

## خروجی مورد انتظار ارزیابی

روی جملهٔ واحد فارسی:

- F0 شادی / خشم > F0 اندوه
- دیرش اندوه > دیرش خشم
- انرژی خشم > انرژی اندوه
- RTF معمولاً خیلی کمتر از ۱ (سریع‌تر از realtime)
- UAR مدل SVM آموزش‌دیده روی ShEMO روی TTS تولیدی بالاتر از شانس (۰.۲۵)؛ به‌خاطر تفاوت دامنه (نمایش رادیویی در برابر گفتار خوانده‌شده) کامل نیست و معیار اصلی جداسازی آکوستیک + شنیدن است

## احساس‌ها

| کلید | فارسی | منبع |
|---|---|---|
| `neutral` | خنثی | AutESD / ShEMO |
| `happy` | شادی | AutESD / ShEMO |
| `angry` | خشم | AutESD / ShEMO |
| `sad` | اندوه | AutESD / ShEMO |
| `fear` | ترس | ShEMO |
| `surprise` | شگفتی | ShEMO |

شدت λ بین ۰ (خنثی) و ۱.۲۵ (اغراق‌شده) قابل تنظیم است. پیش‌فرض دمو ۰.۹۵ است تا احساس در گوش واضح باشد.
